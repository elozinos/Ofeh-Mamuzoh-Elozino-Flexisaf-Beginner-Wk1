Python Fundamentals: Practical Tasks

About the Project

This repository contains eight beginner-friendly Python tasks designed to demonstrate fundamental programming concepts through simple, practical examples.

Topics and Tasks

1. Variables and Data Types

Task: Normal Variables

Demonstrates how to create variables and store different types of data, including strings, integers, floats, and booleans.

2. Conditionals

Task: Grade Checker

Uses if, elif, and else statements to determine a student's grade based on their score.

3. Loops

Task: Number Guessing Game

Demonstrates the use of loops to allow a user to repeatedly guess a secret number until they get it right.

4. Functions

Task: Simple Calculator

Uses functions to perform basic arithmetic operations such as addition, subtraction, multiplication, and division.

5. Modules

Task: Password Generator

Demonstrates how to import and use Python modules to generate random passwords.

6. Error Handling

Task: Calculator with Error Handling

Uses try and except to handle invalid inputs and prevent division by zero from crashing the program.

7. File Handling

Task: To-Do List

Demonstrates how to create, read, and update files to store and retrieve a user's to-do list.

8. Script Organisation

Task: Company Asset Records

Demonstrates how to organise Python code using imports, functions, a main() function, and the if __name__ == "__main__": guard.

Technologies Used

Python 3

Python standard library

Getting Started

Prerequisites

Install Python 3 on your computer.

Running the Programs

Clone this repository:

git clone <your-repository-url>

Navigate to the project folder:

cd <your-project-folder>

Run any task:

python filename.py

Replace filename.py with the name of the Python file you want to run.
